# Data pipeline

Everything the game knows about the Spurs is generated by these four scripts.
They run in order and are safe to re-run — pages and portraits are cached on
disk, so a second run only fetches what is missing.

```bash
node scripts/1-scrape-seasons.mjs 1974 2025   # -> scripts/cache/*.html, seasons.raw.json
node scripts/2-build-vault.mjs                # -> src/data/vault.json
node scripts/3a-fetch-bref-portraits.mjs      # -> public/portraits/*.jpg
node scripts/3b-resolve-portraits.mjs         # fills each player's `img` field
```

## 1 — Scrape seasons

Pulls the per-game table and franchise metadata from Basketball-Reference's
team pages (`/teams/SAS/<year>.html`), one request every 4 seconds to stay
under their 20/minute policy. The three ABA seasons live under the `SAA` code
and were fetched into the same cache by hand.

## 2 — Build the vault

Turns the raw scrape into `src/data/vault.json`:

- filters each roster to real contributors (14+ MPG, 40%+ of team games)
- assigns a G / W / B role from the listed position
- computes the per-game `impact` metric the scorer uses
- tags eras, championship seasons, and postseason results
- ranks every stat as a percentile across all 498 player-seasons, which is how
  a card decides which numbers to headline

## 3 — Portraits

`3a` downloads one 120×180 portrait per player from Basketball-Reference.
`3b` fills the gaps from `cdn.nba.com`, rejecting the generic grey silhouette
the NBA CDN serves for players it has no photo of (detected by hashing every
response and discarding the most-repeated one). Whatever is still missing
falls back to the spur crest in the UI — 66 of 174 players, mostly 1970s–90s
role players neither archive photographed.

Portraits are cached under `public/portraits`, so the running app makes no
external image requests.

## Provenance

Season statistics: Basketball-Reference, 1973-74 through 2024-25.
Portraits: Basketball-Reference and cdn.nba.com.
Spur mark: the team's official primary logo geometry (cdn.nba.com).
