# The Vault

A daily game built from 52 years of San Antonio Spurs box scores.

Five seasons out of franchise history, one per era, drawn fresh each day. Each
one puts three real players from that roster on the table — listed only by
their numbers. Pick one and they join your roster for good. After five rounds
the team is graded out of 100.

```bash
npm run dev
```

## Deploying to Cloudflare Workers

The production Worker path uses Vinext, Cloudflare's current Next.js 16
deployment path. The existing Next.js development and build scripts remain
available.

```bash
# Validate the Worker build locally
npm run build:vinext

# Preview the built Worker at http://localhost:8787
npm run preview:vinext

# Authenticate once, then deploy to your Cloudflare account
npx wrangler login
npm run deploy
```

Regenerate the Worker binding types after changing `wrangler.jsonc`:

```bash
npm run cf-typegen
```

The deploy command targets the Worker named `spurs-vault` from
[`wrangler.jsonc`](wrangler.jsonc). It uses Workers Cache for page caching and
does not require KV, R2, or other provisioned Cloudflare resources. Set an
`account_id` in `wrangler.jsonc` only if your Cloudflare login has access to
multiple accounts; otherwise Wrangler will use the authenticated account.

## The game

Every vault walks chronologically from the ABA years to the present: the five
seasons are drawn one from each fifth of franchise history, so a run always
travels from HemisFair Arena to the Frost Bank Center.

Within a round, the three options always include one of that season's genuine
top players, and are spread across guard / wing / big where the roster allows.
That is what makes it a decision rather than a stat contest — the best player
available and the player your roster needs are often not the same person.

### The Vault Score

| Component | Max | What it measures |
| --- | --- | --- |
| Production | 40 | Did you take the best player on the board? |
| Roster Fit | 25 | Positional spread, plus a creator, a rebounder, a defender and a scorer |
| Star Power | 20 | How close your picks sit to a top-decile Spurs season |
| Efficiency | 15 | Minutes-weighted eFG% against a .500 baseline |

Production is the biggest slice on purpose: the game is a test of judgement,
and the rounds are scored against what was actually available, not against
raw counting stats. Grades run from Teardown up to Dynasty.

## Keeping the answer secret

The whole game rests on not knowing who you're looking at, so the identities
are not in the page:

- The browser receives only the anonymised stat line for each option — no name,
  no portrait path, and not even the internal impact score that would rank
  them.
- When a pick is locked, a server action returns the identities for that
  round's three players. Grading is a server action too, for the same reason.
- Every card wears the same blacked-out figure until it opens. It is cut from a
  real photograph so it reads as a person, but it's one shared silhouette,
  taken from a player who never suited up for San Antonio — so it can't hint at
  anything.

Verified against the build output: no player name, portrait path or dataset
marker appears in any client chunk or in the prerendered HTML.

## Six Clues

The vault's guessing game, at [`/six-clues`](src/app/six-clues/page.tsx). One
player at a time behind a photo blurred past recognition, revealed a clue at a
time. Coyote is always first; after a result, use **Next player** to keep moving
through the pool. Guessing or skipping both spend a clue and sharpen the photo;
six turns, six clues, and the fewer you take the more you bank — 1000 points
down to 100.

Every player has an authored six-clue pack. The mix and order change from
player to player: a pack might use a nickname, draft-night trade, odd bit of
career lore, playoff moment, record, or a useful piece of biographical data.
A wrong guess names the clue it fell foul of, and that reason updates as later
clues land.

**Easy** (the default) draws from 49 entries, including Coyote and Spurs most
fans could name, and
offers a **Hint** button listing everyone the clues haven't ruled out. **Hard**
uses all 66 entries. The player pool covers Coyote, Spurs players with a season
ending in 1999 or later, plus George Gervin, Dennis Rodman, Doc Rivers, and
Avery Johnson. The daily selection and persistence helpers remain in the game
module, commented out of the board while Six Clues is in endless mode.

Every clue's predicate tests exactly what its text says and no more, so the
hint list is honest — a name disappears only because something you were shown
rules it out. Some clues are intentionally broad; a memorable fact can narrow
the field sharply. The six authored clues always identify the target, without
relying on a blind guess.

Data and headshots are generated by
[`scripts/4-build-six-clues.mjs`](scripts/4-build-six-clues.mjs), which is
documented in [`scripts/README.md`](scripts/README.md).

## The data

498 real player-seasons across all 52 Spurs seasons, 1973-74 through 2024-25,
scraped from Basketball-Reference and regenerated by the scripts in
[`scripts/`](scripts/README.md). Stats are per-game as recorded; nothing is
estimated or invented. Portraits are cached locally, so the running app makes
no external requests.

Sixty-six of the 174 players have no portrait in either archive — mostly
1970s–90s role players. Those cards show the spur crest and read "no photo on
file", which is true and suits a game about digging through the vault.

## Built with

Next.js 16 (App Router, Turbopack), React 19, TypeScript, hand-authored CSS
with cascade layers and design tokens. Silver `#C4CED4` and black are the
team's actual primaries; the Fiesta pink / orange / teal show up only as
accents, the way they do on the jerseys.
